# cubby

[cubby](https://cubby.website) is a little directory of websites where
every website gets a point on a map.

## Features
- look at the map! (I designed it with rice!)
- click on map points - or navigator items - to discover new websites!
- read critic-like descriptions of websites as if they were places!

## About
This project was made for [Hack Club](https://hackclub.com/)'s [Siege](https://siege.hackclub.com/), a weekly project challenge. This is week four for me.
